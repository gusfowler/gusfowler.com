Computer Networks at Arizona State University was a series of labs on Red Hat Linux and Cisco IOS routers covering kernel routing, DNS, DHCP, NAT, static addressing and subnetting, TCP congestion control, OpenFlow SDN, and adaptive video streaming with DASH.

The final project, known as "the Socket Project," was to design a communication protocol on top of UDP that let four peers play a card game together.

- Designed the game protocol over UDP, with TCP used for coordination between peers.
- Wrote the application in Python and ran it in Docker so that it was quick to build and test.
