My senior capstone at Arizona State University was a full-stack mobile application for TechDiversified, a startup client, built by an Agile Scrum team of four.

- Built ten screens in React Native for iOS and Android from the client's Figma designs.
- Built the back end as four Docker Compose services: PostgreSQL for storage, GraphQL for the API, and Python to collect and load data.
- Delivered a working minimum viable product the client could show to investors, along with documentation for future development.
